# Contexto curto para iniciar no Google AI Studio

Estou trabalhando em um aplicativo web existente chamado **Mapas Branco Peres**. Stack: React 18, TypeScript, Vite, Tailwind CSS, Mapbox GL / react-map-gl e Supabase opcional. O app é um mapa operacional com pontos de interesse, rotas, GPS, ferramentas de desenho, planejamento agrícola e suporte offline/PWA. A interface principal fica em `src/pages/Home.tsx`; componentes em `src/components/`; hooks em `src/hooks/`; integrações/utilitários em `src/lib/`; estilos globais em `src/index.css`; recursos e dados de mapa em `public/`.

## Instruções de trabalho
- Primeiro analise somente os arquivos que eu fornecer para a tarefa. Não tente reescrever ou reproduzir o projeto inteiro.
- Faça uma alteração pequena e focada, preservando comportamento existente, React/TypeScript e as convenções do projeto.
- Não substitua nem imprima grandes arquivos de dados, GeoJSON, MBTiles, imagens ou lockfiles no chat. Eles são recursos de runtime, não contexto para o modelo.
- Antes de propor mudanças, indique quais arquivos realmente precisam ser alterados. Ao terminar, forneça um diff conciso, dependências novas (se houver) e um teste/comando de validação.
- Se faltarem informações, peça apenas o arquivo ou trecho específico necessário. Nunca invente credenciais; Supabase usa `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` via ambiente.
